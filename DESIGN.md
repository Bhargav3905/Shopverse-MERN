# 🎨 ShopVerse Design System

## Overview

ShopVerse follows a modern, clean and minimal design language inspired by contemporary e-commerce platforms. The interface focuses on readability, consistency and ease of navigation while maintaining a professional appearance across both user and admin panels.

---

## Design Goals

- Simple and intuitive user experience
- Consistent layout across all pages
- Responsive design for multiple screen sizes
- Minimal distractions
- Fast navigation
- Professional admin dashboard
- Accessible color contrast and spacing

---

## Responsive Design

Responsive layouts are built using Bootstrap Grid.

Breakpoints supported:

- Mobile
- Tablet
- Laptop
- Desktop

---

## Animations

Subtle animations are used throughout the project:

- Card hover lift
- Category selection scaling
- Button transitions
- Floating hero image

Animations are intentionally lightweight to preserve performance.
